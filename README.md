# huellitas_bolivia

Requisitos

Visual Studio Code

        Flutter SDK

        Android Studio

        Emulador Android configurado

        Para instalar y configurar Flutter, puedes seguir la guía oficial de Flutter para VS Code.

Cómo ejecutar el proyecto


1. Verificar Flutter

Abrir la terminal de VS Code y ejecutar:

         flutter doctor

Si hay licencias de Android pendientes, ejecutar flutter doctor --android-licenses y aceptarlas.

2. Iniciar el emulador

Abrir Android Studio.

Ir a Tools → Device Manager.

Encender el emulador Android (por ejemplo, Pixel 6).

3. Ejecutar la aplicación

Regresar a Visual Studio Code y ejecutar en la terminal:

          flutter run

La aplicación se abrirá automáticamente en el emulador
